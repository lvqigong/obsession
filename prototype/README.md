# Bear · One Wish Willow — residential horror slice

浏览器 3D 原型：Bear 第一人称，从卧室调查开始，经走廊与前门到门廊查看车灯，再回卧室放回愿望盒，触发愿望解除、Nikki 恢复意识和崩溃尖叫的非血腥结尾演出。它不再把雾林、枯柳或“死在怀里”当作已经核实的电影镜头。Nikki 会优先加载 `../assets/characters/Nikki_Proxy_Original.glb`；网络或模型加载失败时自动回退到程序化角色。

## 启动

在工作区根目录运行 `python -m http.server 5173`，打开 `http://localhost:5173/prototype/`。

需网络加载 jsDelivr 上的 Three.js 0.163.0。模型、贴图标签和音效由代码生成，不下载外部人物模型或商业音乐。

## 操作

- `WASD` 移动；鼠标观察；`Shift` 快走；`F` 手电。
- 床头灯和走廊开关靠近后按 `E` 控制；开关反馈包含声音、灯光强度和门把手晃动。
- 浏览器拒绝鼠标锁定时，按住鼠标左键拖动也可观察。双击画面可再次尝试锁定。
- 靠近物品并面向它，`E` 互动；检查面板打开时，`E` / `I` / `Esc` 关闭。
- 拿起盒子后按 `I` 再次检查。到床头柜旁按 `E` 放下 / 拿起。
- 卧室门和前门都可用 `E` 打开 / 关闭；关门状态会阻挡通行。
- 结尾演出会在靠近 Nikki 后给出扶住/保持视线的交互节点；可按 `Esc` / `Space`，或点击右上角“跳过演出”直接进入结尾画面。
- HUD 右下角“快速检查”按钮，以及数字键 `1`–`5`，用于直接验证卧室、走廊、门廊、回房和终幕章节；正式流程仍按目标推进。

## 完整流程

1. 在右侧床头柜拿起 **One Wish Willow** 盒。
2. 查看床头抽屉、照片、桌上手机、收音机中至少两项线索。
3. 打开卧室门，回看左侧镜面；回应走廊尽头妮基的质问后，电源开关才会可用。
4. 接通走廊灯，再到前门打开门并走上门廊。
5. 走到门廊边缘，按 `E` 查看车灯；车灯熄灭后原路返回卧室。
6. 在床头柜旁按 `E` 放回盒子，自动演出继续到结尾。

## 内容与音乐

- Nikki 优先加载 `../assets/characters/Nikki_Proxy_Original.glb` 原创角色模型；网络或资源加载失败时回退到内置简化轮廓，不仿演员五官。
- 愿望盒表现为三面有棱角的盒子、灰色扭曲塑料枝条和白色椭圆标记。枝条自行折下只是一段自动叙事演出，没有伤害操作或方法。
- 地上尸体通过阴影与布料轮廓表达。结尾是 Nikki 恢复意识、看见现场并崩溃尖叫。
- 音乐槽文字：`Forever (licensed placeholder)`；当前只播放原创合成 drone，标注为 `Love is in the Air Pt.2-inspired drone`，没有嵌入或下载任何商业录音。
- 原型对白、手机留言、收音机内容和照片文字为原创环境叙事，不是电影逐字台词。
